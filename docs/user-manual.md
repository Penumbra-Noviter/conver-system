# 汇流（Conver System 移动端）· 用户使用手册

> 版本：1.1.0（2026-09-21）
> 本手册面向最终用户，介绍 App 的安装、配置与全部功能使用。开发/发布相关见 [README](../README.md) 与 [发布手册](release-android.md)。

---

## 1. 应用简介

**汇流** 是 Conver System 的移动端独立应用（Android），手机独立运行、无需连接电脑或任何后端服务。App 内置多个主流大语言模型（LLM）直连通道，支持：

- 与 AI 角色实时聊天（流式输出、多候选回复）
- 创建与管理角色卡片（含导入导出）
- 跨对话全文搜索
- 文档解析（导入文件交给 AI 提炼要点）
- AI 生成与运行网页游戏（内置 22 款随包游戏 + 导入自定义游戏）
- 聊天增强：世界书设定、记忆宫殿、叙述风格、预设对话、专家模式、采样参数、Prompt 调试、分支对话

## 2. 安装

- **侧载安装**：将 `app-release.apk` 拷贝到手机后点击安装（需允许「安装未知来源应用」）。手机需 Android 8.0 或更高。
- 应用名显示为「汇流」；首次安装后桌面图标为自适应图标。

## 3. 首次启动：配置 AI 服务

聊天与文档解析依赖大模型服务，首次使用需在 **设置 → 模型服务** 中配置：

1. 选择服务商（Provider）——支持 Anthropic Claude 与 OpenAI 兼容接口（含国产兼容厂商）。
2. 填入 **API Key**——Key 仅保存在本机安全存储（SecureStorage），不会写入聊天记录，也**不会注入到游戏**（模拟器只注入你显式允许的厂商 Key）。
3. 如需自定义服务地址，在「接口地址（Base URL）」填入（OpenAI 兼容格式）。
4. 选择默认模型，然后点 **测试连接** 验证配置可用（显示成功即可开始使用）。

> 配置仅影响 AI 调用；不配置也能浏览角色列表、阅读已有对话、玩本地游戏等离线功能。

## 4. 聊天

- **发送消息**：底部输入框输入后发送；回复为流式逐字显示（打字机效果）。
- **停止 / 重试**：回复过程中可「停止」；回复中断（断网/超时）时会标记「回复中断」，可点击重试（重新生成）。
- **重新生成**：长按消息可选择重新生成回复（对同一轮产出新回答）。
- **多候选回复（swipes）**：一条消息可能有多个候选回复，左右滑动或从消息菜单切换。
- **消息编辑 / 删除**：长按消息可编辑后重发、或删除单条；删除用户消息会连其后回复一并截断。
- **继续回复（续写）**：在最后一条 AI 回复之后继续生成。
- **分支对话**：从任意消息分叉出新对话分支，互不干扰。
- **跟随引导**：首次使用有分页新手指引，可跳过。

## 5. 角色

- **创建角色**：底部导航「角色」→ 新建 → 6 步全屏向导（名称、头像、性格、开场白、预设模板等），内置 5 种模板可一键套用。
- **角色卡**：每张卡显示头像/名称/简介，支持下拉刷新、长按批量删除。
- **导入 / 导出**：角色卡支持 V2 格式 JSON 导入导出（可分享给他人或从桌面版迁移）。
- **角色记忆**（人机恋增强）：
  - 对话中 AI 会自动提炼并记住你的人格事实（可在设置中开关）。
  - 「记忆」页可查看/增删记忆条目、提出「人设演化」建议（AI 提出演化 → 你确认应用或拒绝）。
  - 支持跨会话语义检索（在 **设置 → 对话 → 语义检索** 开启 Embedding 服务后，AI 能跨会话回忆相关内容，配置见 §9.1）。
- **世界书（Lorebook）**：为角色设定背景设定条目，对话中按关键词自动注入，增强角色一致性。
- **预设对话**：为角色配置预设开场场景，新建对话时可选。
- **专家模式 / 叙述风格 / 采样参数**：在对话设置中可切换专家提示词、调整叙述口吻与随机性（温度、max tokens 等；角色级设置优先、全局兜底）。
- **Prompt 调试**：开发者/高级用户可查看发送给模型的完整提示词（只读，不修改任何行为）。

## 6. 搜索

顶部搜索框输入关键词，跨全部对话全文搜索（输入停顿后自动搜索）。结果按对话聚合，点击结果跳转到对应对话并高亮定位（3 秒）。

## 7. 文档解析

在聊天输入区附近或文档入口选择文件（文本/JSON 等），App 调用模型提取内容要点生成结构化摘要或列表，可继续追问。解析结果可作为对话内容保存。

## 8. 游戏与模拟器（AI 生成游戏）

- 内置 **22 款随包网页游戏**（列表页四态：加载/就绪/运行/错误；点击即玩，懒启动不占资源）。
- 游戏在本机本地 HTTP 服务运行（`127.0.0.1:8642`），不联网也可玩内置游戏。
- **AI 生成游戏**：在「模拟器 → 生成」输入玩法描述，AI 生成可运行的游戏页面后自动注入。
- **导入游戏**：导入他人分享的游戏文件（HTML/压缩包），自动去重；恶意内容有二次确认拦截。
- **卡片简介**：内置游戏随包自带简介；导入的自定义游戏会自动从文件内容生成一句简介（可在 **设置 → 对话 → 模拟器简介** 开启「简介 LLM 精修」，用已配置的模型生成更有特点的文案）。
- **存档管理**：游戏进度（localStorage）本地保存，可查看/备份/恢复/清空；不同游戏互不越权。
- **Key 注入**：需要联网的 AI 驱动游戏会请求你的 Key——只注入你显式允许的厂商 Key，**Claude Key 永不进游戏**，且使用前有明确提示。

## 9. 设置

- **外观**：主题三值切换（跟随系统 / 浅色 / 深色）。
- **模型服务**：服务商、Key、地址、默认模型、测试连接（见 §3）。
- **对话参数**：全局温度 / 最大 Token 数（角色级为主，此处为兜底）。
- **记忆与反思**：对话记忆开关（后台反思提炼人格事实）、Embedding 语义检索开关与服务地址（OpenAI 兼容 `/embeddings`，配置见 §9.1）。
- **主动消息与关系**：主动消息（角色在空闲时给你发消息——通过系统通知到达，点击通知直达对话）；关系状态（对话推进角色关系亲密度，可在角色卡查看进度，升级需你确认）。
- **内心独白**：AI 的内心想法（`<thought>`）默认恒剥离显示为灰色斜体，可在设置开关。
- **模拟器简介**：导入游戏自动从文件内容生成简介（规则提取，零成本）；「简介 LLM 精修」开关在对话设置页（默认关，开启后调用已配置 LLM 生成更有特点的文案）。
- **通知**：Android 13+ 需在系统设置允许通知，App 内请求权限。
- **隐私与关于**：隐私说明、版本信息、桌面版说明。

## 9.1 语义检索（Embedding）配置

跨会话语义检索默认**关闭**：开启后，AI 能跨会话回忆相关内容（记得你在其他对话里说过的事），而不只局限于当前会话。

**找到入口**：设置 →「对话」（生成参数与行为）→ 找到「语义检索」区块。

**配置步骤**：

1. 打开「启用语义检索」开关（关闭状态下输入框不可编辑）。
2. **API Key**：填入所用 Embedding 服务商的 Key，仅保存在本机安全存储；若与「模型服务」共用同一个 OpenAI 兼容服务商，可留空自动复用其 Key。
3. **Base URL**（可选）：留空使用官方默认端点；自定义服务商地址必须以 `https://` 开头（OpenAI 兼容 `/embeddings` 语义）。
4. **模型**：填所选服务商的 Embedding 模型名；留空使用缺省 `text-embedding-3-small`。
5. 点 **测试连接** 验证——成功即配置可用，之后对话会自动执行跨会话语义检索。

**模型怎么选**：任何提供 OpenAI 兼容 `/embeddings` 接口的服务商都可以，例如 OpenAI 官方 `text-embedding-3-small`，或国产兼容服务商（如 SiliconFlow 的 `BAAI/bge-m3`）。模型名须与服务商文档一致。

> 隐私提示：开启后，对话内容会发送至所选 Embedding 服务用于生成语义向量；默认关闭，请按隐私偏好决定是否开启。

## 10. 数据与隐私

- 全部数据保存在**本机** SQLite 数据库（对话/角色/记忆/存档），不经过任何第三方服务器。
- API Key 仅存本机安全存储；发送给模型的只有你的对话内容与注入的设定文本。
- App **不含任何第三方广告/统计 SDK**（零第三方 SDK，详见 [Android 隐私清单](privacy-android.md)）。
- 卸载 App 会删除本机全部数据；需要保留数据请先使用导出功能。

## 11. 常见问题

| 问题 | 处理 |
|---|---|
| 测试连接失败 | 检查网络、Key 是否有效、Base URL 是否填对（OpenAI 兼容厂商需含 `/v1` 语义）；断网时自动重试 2 次 |
| 语义检索没生效 | 确认「设置 → 对话 → 语义检索」开关已打开且「测试连接」成功；语义检索使用独立的 Embedding 服务配置，与聊天主模型无关 |
| 回复中断 | 网络波动时会标记「回复中断」，点击重试即可重新生成；若持续失败检查 Key 余额/限流 |
| 收不到主动消息 | Android 13+ 检查系统通知权限是否允许；App 内「主动消息」开关是否打开 |
| 游戏打不开 | 内置游戏均为本地运行；若为 AI 生成/联网游戏，检查网络与是否已授权 Key 注入 |
| 导入的角色卡打不开 | 确认是 V2 格式 JSON；导入页会提示具体原因 |
| 升级后数据还在吗 | 在——数据在本地数据库，升级不覆盖；卸载才删除 |
