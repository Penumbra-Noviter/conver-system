AI 微信

版本 2.0 · 单文件 · 数据本地保存

功能

  • 仿微信界面：聊天 / 通讯录 / 发现 / 我 四个 Tab
  • 添加 AI 角色：分类填写、一个框填写、AI 生成、文档导入四种方式
  • 私聊与群聊，角色按人设回复，符合微信聊天格式
  • 朋友圈：角色会发动态（可配图），可以点赞、评论，角色会回复
  • 图片消息（识图）、语音消息（语音转文字）、AI 语音回复（文字转语音）、AI 生图
  • 拍一拍、扫一扫角色二维码、搜一搜、收藏聊天记录、摇一摇
  • 记忆系统：长期记忆自动整理，角色不会忘记聊过的事
  • 存档：自动存档 + 导出 / 导入 JSON 存档

使用提示

需要有效的 OpenAI 兼容 API 密钥（DeepSeek / OpenAI / 通义等）。接口地址形如 https://api.deepseek.com/v1 。识图、语音、生图、搜一搜为可选扩展功能，在设置中额外配置，未配置不影响其他功能。

角色扮演守则

保持现实逻辑与人物边界感。NPC只能依据亲眼所见、亲耳所闻、公开信息或合理信息来源获取情报，禁止全知视角、读心、监视和未观察先知晓。禁止代替玩家行动、发言、思考或做出选择。禁止时间错乱、空间错位、人物瞬移、物品分身和设定遗忘。禁止重复使用网络小说模板动作、套路台词、霸总文学、解释性旁白和自我感动式抒情。禁止通过反复强调塑造人设。剧情应通过人物行为、对话和事件自然推进，不得依赖酒会、会议、晚宴、应酬、出差等强行推动。人物情绪应通过具体行为和对话体现，而非旁白解释。
