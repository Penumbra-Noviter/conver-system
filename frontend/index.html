快速开始 ¶

Conver System 是一个本地优先的 AI 角色对话与模拟器平台：创建角色、开启对话、玩 AI 模拟器，所有数据保存在本地。整体流程：配置 AI 接口 → 创建角色 → 开始聊天（或打开模拟器）。

  1. 配置 AI 接口 — 首次使用，先点击侧栏「设置」，填入你的 Claude 或 OpenAI 兼容 API Key（详细教程见下方 「配置你的 AI 接口」）。尚未配置 Key 时，聊天视图会显示「先配置 AI 接口」引导卡，点击「前往设置」即可直达设置页。
  2. 创建角色 — 点击「角色」视图的「创建角色」按钮，跟随 6 步引导向导创建（也可选内置模板或用文档导入由 AI 自动解析）。
  3. 开始对话 — 在角色卡片上点击「对话」按钮，系统自动创建新对话并立即显示角色开场白，在输入框中打字发送即可。
  4. 玩模拟器 — 点击侧栏「模拟器」，选择一款内置 AI 游戏开始体验，或点击「AI 生成」用你的世界观描述让 AI 生成专属游戏（AI 游戏需先完成第 1 步配置，见 「模拟器使用指南」）。

配置你的 AI 接口（新手必读） ¶

所有 AI 功能（角色对话、AI 模拟器）共用同一套接口配置，只需配置一次，全局生效。

  1. 准备 API Key：在模型服务商官网注册并创建密钥。任选一个服务即可：
    • Anthropic Claude — Key 以 sk-ant- 开头
    • OpenAI 兼容服务 — OpenAI、DeepSeek、通义千问、Kimi、智谱 GLM 等（Key 以 sk- 开头）
  2. 填入设置页：进入「设置」，在「API 密钥」区把 Key 填入「Claude API Key」或「OpenAI / 国产模型 API Key」任一栏。系统会先按所选模型的协议匹配，未匹配时自动使用另一栏——所以只填一栏就能用，两栏都填也行。
  3. 兼容服务地址（可选）：使用官方服务时地址留空即可；使用第三方兼容服务时，在对应的「兼容 API 地址」填入 base_url（例如 DeepSeek 填 https://api.deepseek.com/v1）。
  4. 选择默认模型：在「默认模型」区选择 Provider 和模型；若列表里没有你想要的，在底部选择「自定义模型」并手动输入模型名称（如 deepseek-chat、qwen-plus）。
  5. 保存：点击「保存设置」。API Key 仅存储于本地数据库，不会上传。

怎么判断配置成功？尚未配置 Key 时，聊天视图的空态会显示「先配置 AI 接口」引导卡（点「前往设置」直达设置页）。配置好 Key 后引导卡自动消失；回到聊天视图，给任意角色发一条消息即可验证。模拟器游戏则在运行页点「重新同步」让新配置生效。

角色管理 ¶

角色是对话的核心，每个角色拥有独立的人设、语气和知识设定。

  • 创建角色（引导向导）：点击「创建角色」后，向导分 6 步引导完成：选择创建方式（文档导入 / 模板 / 手动）→ 导入文档或选择模板 → 基本信息（姓名 / 头像 / 描述 / 标签）→ 人格设定 → 对话风格（开场白 / 示例对话）→ 预览保存。带 * 的为必填项。
  • 内置模板：向导内置 5 个通用角色模板（知性学姐、神秘旅人等），选择后可直接使用，也可以在其基础上修改。
  • 文档导入：在向导第一步选择「文档导入」，把角色设定文档、小说片段或简介粘贴进去，点击解析，AI 会自动提取角色信息填入后续表单（此功能需要已配置 AI 接口）。
  • 编辑角色：点击角色卡片上的「编辑」按钮修改已有角色（使用简洁表单）。
  • 删除角色：点击角色卡片上的「删除」按钮。如果有进行中的对话，系统会提示关联对话数量。
  • 导入角色卡：点击「导入角色」按钮，选择 SillyTavern V2 格式的角色卡 JSON 文件（兼容 V1 旧卡与裸 data 格式）。
  • 导出角色卡：点击角色卡片上的「导出」按钮，导出为 V2 格式的角色卡 JSON，方便备份或分享。

对话功能 ¶

  • 多会话标签页：可以同时打开多个对话，聊天区顶部的标签条随时切换。每个标签独立记忆输入草稿、滚动位置和生成状态——切到别的对话后，原对话的 AI 回复会继续在后台生成。
  • 发送消息：在输入框输入文字，按 Enter 发送，Shift+Enter 换行。
  • 流式输出：默认开启，AI 回复会逐字显示（打字机效果）。可在输入框下方取消勾选「流式输出」切换为一次性输出。
  • 停止生成：流式输出时，「发送」按钮会切换为红色「停止生成」按钮，点击即可中断 AI 回复，已生成的内容会保留。
  • 复制消息：鼠标悬停在消息气泡上，右上角会显示「复制消息」按钮，点击即可复制该条消息内容。
  • 对话标题：创建对话时角色开场白立即显示；发送首条消息后自动生成标题（格式：与 {角色名} 的对话），你也可以点击头部标题直接编辑。
  • 删除对话：在对话列表中，鼠标悬停显示「删除」按钮，点击即可删除。
  • 导出对话：在聊天头部点击「导出」按钮，可选择 JSON 或 Markdown 格式导出完整对话记录。

模拟器使用指南 ¶

「模拟器」板块提供多款 AI 驱动的沉浸式游戏（人生模拟器、仙途、仿微微信 AI、克苏鲁跑团、侦探模拟等），游戏在应用内部打开，存档保存在浏览器本地。

  • 游戏列表：进入模拟器视图即显示全部游戏卡片，顶部可按「全部 / AI 驱动 / 纯本地」筛选。卡片右下角标注「AI 生成」徽标的为通过 AI 生成功能创建的游戏。点击顶部工具栏的 Sparkles 图标可打开生成对话框（详见 「AI 生成游戏」）。
  • 导入游戏：点击列表右上角「导入游戏」按钮选择文件，或直接把 .html 文件拖入列表区域，即可把第三方游戏加入列表（仅支持本地 .html 文件，≤5MB，一次一个）。内容与已有游戏相同的文件会自动识别并提示（SHA-256 去重）；文件名冲突时自动改名为 xxx-2.html 等递增后缀。导入成功的游戏会自动注入 PC 阅读覆盖层并做覆盖适配分析，未覆盖项会提示——详见下方 「导入游戏与安全须知」。
  • AI / 纯本地识别：导入后系统自动判断游戏类型（AI 驱动需配置接口 / 纯本地无需配置）。若 AI 驱动游戏被误判为「纯本地」，可在卡片上点击「重新识别」按钮修正——系统会重新分析 HTML 中的配置控件并更新分类。
  • 开始与退出游戏：点击任意卡片即可进入游戏；点击左上角「返回」回到列表，进度不会丢失（存档自动保存，重进自动恢复）。
  • AI 游戏需要配置接口：AI 驱动游戏会提示「此游戏需自行配置 AI 接口」。先在「设置」页配置好 API Key（见 「配置你的 AI 接口」），再回到游戏点击「重新同步」，配置会自动写入游戏；也可以先配好设置再打开游戏，加载后会自动同步。游戏运行中重建了配置控件也会自动再同步。
  • 存档管理：列表右上角「存档管理」按钮可查看每个游戏的存档情况（存档键数 / 总大小），并支持：
    • 导出：把某游戏的全部存档下载为 JSON 文件做备份（注意：导出文件可能包含游戏内配置数据，如 API Key，请妥善保管）。
    • 导入：把之前导出的 JSON 存档恢复到浏览器（仅接受该游戏的合法存档键，其他内容会被拒绝）。
    • 删除：清除某游戏的全部存档（删除前需要确认，且不可恢复）。
  • 存档位置：存档保存在浏览器的 localStorage 中，按游戏前缀隔离。换浏览器或清理浏览器数据会导致存档丢失，重要进度建议用「存档管理」导出备份。
  • 特别说明：小马宝莉、高中生模拟器两款游戏的存档仅会话内生效，重进需要重新注入；个别游戏没有存档管理功能，属正常现象。

AI 生成游戏 ¶

输入世界观描述，AI 自动生成完整的 HTML 模拟器游戏。生成的游戏与其他模拟器一样运行，支持存档、覆盖层适配和 per-game CSS。

  • 进入方式：在模拟器列表页，点击顶部工具栏的「AI 生成」按钮（Sparkles 图标）打开生成对话框。
  • 编写世界观：在对话框中填写「世界观设定」（必填），描述你的世界背景、氛围、核心冲突等。越详细，生成的游戏越丰富。也可以上传 .txt / .md 文件代替粘贴。可选填「游戏名称」。
  • 生成流程：点击「生成游戏」后，后端 AI 会根据你的描述填充种子模板，生成完整的 HTML 游戏文件，并通过六项校验闸门（结构完整性 / 模板标记 / 配置契约 / HTML 可解析性 / 安全性 / 游戏数据完整性）。校验失败时自动重试打磨（最多 3 次），并显示具体错误和建议。
  • 生成完成：成功生成的游戏会出现在模拟器列表中，卡片右下角标注「AI 生成」徽标。与导入的游戏一样，打开后自动注入 PC 阅读覆盖层，支持存档和 AI 配置同步。
  • 需先配置 AI 接口：游戏生成功能依赖后端 AI 推理，需要先在「设置」页配置好 API Key（见 「配置你的 AI 接口」）。
  • 生成限制：世界观描述最多 10000 字符；上传文件最大 10MB；生成请求超时 2 分钟。

导入游戏与安全须知 ¶

安全警告：第三方游戏可读取本地数据并调用 API。导入的游戏与内置游戏同处本地同源区域运行，可读取本应用本地数据（含你配置的 API 凭证）并调用本应用 API 端点——请仅导入你信任的文件。导入前程序会弹出同样的警告并需要你确认。

  • 恶意模式扫描：导入时程序会扫描明显恶意模式——eval() 动态执行、读取 document.cookie、跨域 fetch 请求等，命中会弹出「安全警告」提示，但不会拦截导入（静态审查不承诺防住一切，仅作知情提示）。
  • 重复导入：内容与已有游戏相同的文件（SHA-256 校验）会被识别并提示已存在，不会重复导入。
  • 自动改名：文件名与已有游戏冲突时自动改名为 xxx-2.html 等递增后缀，导入成功后提示新文件名。
  • 覆盖层适配：导入的游戏运行时自动注入 PC 阅读覆盖层；若检测到可能未被覆盖的类名 / 变量 / 字号，会弹出「覆盖层适配提示」并列出清单。
  • 自定义样式（per-game CSS）：如需按此游戏微调样式，把 CSS 命名为 <game-id>.css 放入数据目录（默认 %APPDATA%\ConverSystem\simulators\），该样式会在共享覆盖层之后注入，可覆盖默认适配。

搜索消息 ¶

在「搜索」视图中输入关键词，系统会跨所有对话搜索匹配的消息。搜索结果会显示消息内容预览、角色归属和对话名称，点击结果可跳转到对应对话。

设置说明 ¶

  • API 密钥：Claude 与 OpenAI 兼容两栏，填任一栏即可全局生效（系统按所选模型的协议自动匹配，未匹配时使用另一栏）。第三方服务需同时填写对应「兼容 API 地址」。
  • 默认模型：选择默认的 Provider 和模型；列表底部可选「自定义模型」手动输入名称。
  • 上下文轮数：控制 AI 能记住的对话轮数（默认 30 轮，可调范围 5–100）。轮数越多，AI 对上下文的记忆越好，但 Token 消耗也越大。
  • 模板变量：在角色设定中使用 {{user}}（自动替换为用户昵称）和 {{char}}（自动替换为角色名），让角色设定更生动自然。
  • 主题模式：支持跟随系统、浅色、深色三种选择；侧栏底部的太阳按钮可快速切换。
  • 关闭窗口行为（仅桌面版）：首次运行会询问关闭主窗口时的行为，之后可在设置页随时修改——「最小化到托盘（后台继续运行）」或「直接退出程序」。选择最小化后，可从系统托盘图标恢复或退出程序。
  • 清空所有对话（危险操作）：将删除所有对话和消息记录，此操作不可撤销，请谨慎使用。

桌面版功能（Tauri） ¶

Conver System 提供基于 Tauri 的桌面应用程序，支持 Windows 原生体验。桌面版与网页版功能一致，额外提供以下特性：

  • 随包运行：桌面版内置 Python 后端，启动时自动拉起服务，关闭时自动清理。无需手动启动 uvicorn 或维护两个窗口。
  • 关闭窗口行为：首次运行会询问关闭主窗口时的行为——「最小化到托盘（后台继续运行）」或「直接退出」。选择最小化后，应用驻留系统托盘，可从托盘图标恢复或退出；之后可在设置页随时修改这一偏好。
  • 系统托盘：最小化到托盘后，应用在后台继续运行（对话中的 AI 回复不受影响），右键托盘图标可选「显示窗口」或「退出」。
  • 数据目录：所有数据（角色、对话、模拟器游戏、manifest）保存在 %APPDATA%\ConverSystem\ 目录下。网页版的数据在此目录外独立管理。
  • 安装器：Windows 安装包（NSIS 安装器）支持自定义安装路径、开始菜单快捷方式。「卸载」可从控制面板程序列表执行。

支持的模型 ¶

系统通过统一的 Provider 抽象层支持多种模型服务，当前已内置：

  • Claude（Anthropic）— Claude Sonnet 5、Claude Opus 4.8 等
  • OpenAI — GPT-4o、GPT-5 系列等
  • DeepSeek — deepseek-v4-flash、deepseek-v4-pro 等
  • 通义千问（Qwen）、Kimi（Moonshot）、智谱（GLM）、MiniMax、阶跃星辰（Step） 等国产模型

所有兼容 OpenAI 接口的服务均可通过在设置页填入对应 base_url 使用；列表里没有的模型可选「自定义模型」手动输入。

常见问题 ¶

  • AI 不回复或报错？先到「设置」确认 API Key 已保存且格式正确；模拟器游戏请在运行页点击「重新同步」让配置生效。使用第三方服务时，还需确认 base_url 与模型名称填写正确。
  • 模拟器提示「游戏加载失败」？通常是页面加载超时（15 秒）或参数异常，点击「重试」即可；游戏文件就在本地，不会丢失。
  • 游戏存档会丢吗？正常使用不会丢（保存在浏览器 localStorage）。清理浏览器数据、换浏览器或换电脑前，建议先用「存档管理」导出备份。
  • 数据安全吗？角色、对话、API Key 全部保存在本地，只有聊天内容会发送给你自己配置的模型服务商。

小贴士 ¶

  • 角色的人格设定越详细，AI 的角色扮演效果越好。建议包含：性格特征、说话风格、背景故事、知识范围。
  • 开场白（first_mes）是角色与用户的第一句话，好的开场白能立刻建立角色氛围。
  • 使用 {{user}} 和 {{char}} 模板变量时，确保已在设置中填写了用户昵称。
  • 侧栏可以收起（侧栏底部按钮），收起后点击左上角悬浮按钮展开；聊天列表也可单独收起，腾出更多聊天空间。
  • 聊天标签页支持多会话同时打开，切换标签后原对话的 AI 回复会继续在后台生成，切换回来时内容已自动更新。
  • 生成 AI 游戏时，世界观描述越具体（氛围、时代、核心冲突、角色关系），生成的游戏越丰富有趣。同一描述可以多次生成，每次结果不同。
  • 导入的第三方游戏如果排版不理想，可制作 <game-id>.css 放入数据目录覆盖默认样式（见 「导入游戏与安全须知」）。
  • 遇到问题可以先查看浏览器开发者工具的控制台（F12）是否有错误提示。
