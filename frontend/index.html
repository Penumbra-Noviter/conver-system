用户手册

📖 快速开始

Conver System 是一个角色对话系统，让你与 AI 驱动的虚拟角色进行多轮对话。整体流程：创建角色 → 开启对话 → 开始聊天。

  1. 配置 API 密钥 — 首次使用，先点击侧栏「设置」，填入你的 Claude / OpenAI 兼容 API Key 和地址，保存即可。
  2. 创建角色 — 点击「角色」视图的「创建角色」按钮，填写角色姓名、人格设定、开场白等信息。
  3. 开始对话 — 在角色卡片上点击「对话」，系统自动创建新对话，在输入框中打字发送即可。

🎭 角色管理

角色是对话的核心——每个角色拥有独立的人设、语气和知识设定。

  • 创建角色：填写姓名、人格设定（系统提示词）、开场白、语气风格、标签等信息。带 * 的为必填项。
  • 编辑角色：点击角色卡片上的「编辑」按钮修改已有角色。
  • 删除角色：点击角色卡片上的「删除」按钮。如果有进行中的对话，系统会提示关联对话数量。
  • 导入角色：点击「导入角色」按钮，选择 SillyTavern V2 格式的角色卡 JSON 文件（兼容 V1 旧卡与裸 data 格式）。
  • 导出角色：点击角色卡片上的「📤」按钮，导出为 V2 格式的角色卡 JSON。

💬 对话功能

  • 发送消息：在输入框输入文字，按 Enter 发送，Shift+Enter 换行。
  • 流式输出：默认开启，AI 回复会逐字显示（打字机效果）。可在输入框下方取消勾选「流式输出」切换为一次性输出。
  • 停止生成：流式输出时，发送按钮会变为红色「⏹」停止按钮，点击即可中断 AI 回复，已生成的内容会保留。
  • 复制消息：鼠标悬停在消息气泡上，右上角出现「📋」复制按钮，点击复制该条消息内容。
  • 对话标题：发送首条消息后，系统自动生成标题（格式：与 {角色名} 的对话）。你也可以点击头部标题直接编辑。
  • 删除对话：在对话列表中，鼠标悬停显示删除按钮，点击即可删除。
  • 导出对话：在聊天头部点击「导出」按钮，可选择 JSON 或 Markdown 格式导出完整对话记录。

🔍 搜索消息

在「搜索」视图中输入关键词，系统会跨所有对话搜索匹配的消息。搜索结果会显示消息内容预览、角色归属和对话名称，点击结果可跳转到对应对话。

⚙️ 设置说明

  • API 密钥：填入 Claude 或 OpenAI 兼容 API 的 Key 和地址。只需填任一栏（Claude 或 OpenAI），系统即可全局使用——选择任意模型时自动匹配对应协议。
  • 默认模型：选择默认的 Provider 和模型。自定义模型可在下拉列表底部选择「自定义模型」手动输入。
  • 上下文轮数：控制 AI 能记住的对话轮数（默认 30 轮）。轮数越多，AI 对上下文的记忆越好，但 Token 消耗也越大。
  • 模板变量：在角色设定中使用 {{user}}（自动替换为用户昵称）和 {{char}}（自动替换为角色名），让角色设定更生动自然。
  • 主题模式：支持跟随系统、深色模式、浅色模式三种选择。

🧠 支持的模型

系统通过统一的 Provider 抽象层支持多种模型服务，当前已内置：

  • Claude（Anthropic）— Claude Sonnet 5、Claude Opus 4.8 等
  • OpenAI — GPT-4o、GPT-4-turbo 等
  • DeepSeek — deepseek-v4-flash 等
  • 通义千问（Qwen）、Kimi、智谱（GLM）、Moonshot 等国产模型

所有兼容 OpenAI 接口的服务均可通过填入对应 base_url 使用。

💡 小贴士

  • 角色的人格设定越详细，AI 的角色扮演效果越好。建议包含：性格特征、说话风格、背景故事、知识范围。
  • 开场白（first_mes）是角色与用户的第一句话，好的开场白能立刻建立角色氛围。
  • 使用 {{user}} 和 {{char}} 模板变量时，确保已在设置中填写了用户昵称。
  • API Key 仅存储在本地 SQLite 数据库中，不会上传到任何服务器。
  • 遇到问题可以先查看浏览器开发者工具的控制台（F12）是否有错误提示。
